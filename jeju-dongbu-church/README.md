# 제주동부교회 홈페이지

한 페이지짜리 정적 사이트. GitHub Pages로 배포하고, Firebase(Firestore + Authentication) 무료 플랜으로
메뉴 편집·글쓰기·사진 업로드를 관리자만 할 수 있게 만들었습니다. 방문자는 로그인 없이 보기만 가능합니다.

## 파일 구성

```
index.html
css/style.css
js/firebase-config.js   ← 여기에 Firebase 프로젝트 값을 채워야 합니다
js/app.js
firestore.rules         ← Firebase 콘솔의 Firestore 규칙에 붙여넣을 내용
```

## 1. Firebase 프로젝트 만들기

1. [console.firebase.google.com](https://console.firebase.google.com)에서 구글 계정으로 로그인 후 **프로젝트 추가**.
2. 프로젝트 이름은 자유롭게 (예: `jeju-dongbu-church`). Google Analytics는 꺼도 됩니다.
3. 왼쪽 메뉴 **빌드 > Firestore Database** → **데이터베이스 만들기** → 위치는 `asia-northeast3(서울)` 추천 → 처음엔 아무 모드로 시작해도 됩니다 (규칙은 아래에서 다시 설정).
4. 왼쪽 메뉴 **빌드 > Authentication** → **시작하기** → 로그인 방법 탭에서 **이메일/비밀번호** 사용 설정.
5. Authentication의 **Users** 탭 → **사용자 추가** → 관리자로 쓸 이메일/비밀번호 1개를 직접 등록 (교회 관리자용 계정).

## 2. 웹 앱 등록 & 설정 값 복사

1. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정** → 아래로 스크롤해 **내 앱** → `</>` (웹) 아이콘 클릭.
2. 앱 닉네임 아무거나 입력 → **앱 등록**. Firebase Hosting은 설정하지 않아도 됩니다.
3. 화면에 나오는 `firebaseConfig` 객체 값을 복사해 [js/firebase-config.js](js/firebase-config.js)의 각 항목에 붙여넣으세요.

## 3. 보안 규칙 적용

Firestore Database → **규칙** 탭을 열고, [firestore.rules](firestore.rules) 내용을 그대로 붙여넣은 뒤 **게시**.
누구나 읽을 수 있지만, 글쓰기·수정·삭제·메뉴 변경은 로그인한 사용자만 가능하도록 되어 있습니다.

## 4. 로컬에서 미리보기

`index.html`을 더블클릭해서(=`file://`) 열면 브라우저가 ES 모듈을 막아 Firebase가 동작하지 않습니다.
아래처럼 로컬 서버로 열어주세요.

```bash
npx serve .
```

또는 Python이 있다면:

```bash
python3 -m http.server 5500
```

이후 브라우저에서 `http://localhost:5500` 접속.

## 5. GitHub Pages 배포

```bash
git init
git add .
git commit -m "제주동부교회 홈페이지"
git branch -M main
git remote add origin <본인 GitHub 저장소 주소>
git push -u origin main
```

GitHub 저장소 → **Settings > Pages** → Source를 `Deploy from a branch`, 브랜치 `main` / `/root`로 지정 후 저장.
몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/`에서 확인할 수 있습니다.

## 사용법

- 사이트 하단 **관리자 로그인** 버튼으로 로그인하면 화면 위쪽에 관리자 바가 나타납니다.
- **메뉴 편집**: 상단 탭의 이름·순서·연결 섹션(`#worship`처럼 `id`로 이동)을 바꾸고 저장하면 모든 방문자에게 즉시 반영됩니다.
- **대표사진 변경**: 첫 화면(히어로) 배경을 교회 전경사진으로 바꿉니다. 관리자가 로그인하지 않은 동안은 은은한 조명 느낌의
  기본 배경이 보이고, 로그인 상태에서 사진을 등록하지 않았을 땐 히어로 상단에 안내 문구가 표시됩니다.
- **글쓰기**: 소식 게시판에 제목·내용·사진(선택)을 올립니다. 사진은 자동 압축되어 저장됩니다.
- 각 게시글 카드의 **수정/삭제**도 관리자 로그인 상태에서만 보입니다.

## 실제 정보 반영 안내

`index.html`의 교회 이름·주소(제주특별자치도 제주시 고마로7길 11)·전화(064-722-0067)·팩스(064-758-0068)·
담임목사/부목사 성함·예배 시간표는 제주동부교회 공식 홈페이지(dbchurch.org)에 게시된 내용을 참고해 채웠습니다.
다만 아래 항목은 초안이거나 확인이 더 필요하니, 게시 전에 꼭 확인해주세요.

- **교회소개 문단**과 **비전/사명 3개 항목**은 제가 새로 쓴 초안입니다. 원래 홈페이지의 담임목사 인사말·교회비전 페이지는
  텍스트가 아니라 이미지로 되어 있어 그대로 가져올 수 없었고, 저작권 문제로 원문을 그대로 옮기지도 않았습니다.
  실제 인사말 내용으로 다시 작성해주세요.
- **히어로 대표사진**은 일부러 넣지 않았습니다. 원래 사이트가 성산일출봉 쪽이 아닌 고마로(제주시 시내)에 있어서
  이전 초안의 바닷가 일출 이미지는 실제와 맞지 않았고, 원 사이트에서 뚜렷한 교회 건물 전경사진도 찾지 못했습니다.
  대신 관리자 로그인 후 **대표사진 변경** 기능으로 실제 교회 건물 사진을 직접 올려주세요.
- **교회 연혁**(1908년 설립 이후 주요 사건)은 원 사이트에 이미지로만 있어 옮기지 못했습니다. 필요하면 소식 게시판에
  글로 정리해 올리거나, `index.html`의 교회소개 섹션에 추가해주세요.

## 참고 / 한계

- 이미지는 별도 Storage 없이 Firestore 문서 안에 base64로 압축 저장합니다(문서당 약 1MB 제한). 사진이 아주 많거나
  고화질 원본을 그대로 보관해야 한다면 Firebase Storage(Blaze 요금제) 연동으로 바꾸는 걸 권장합니다.
- 현재 보안 규칙은 "로그인한 사용자라면 누구나 쓰기 가능"입니다. 관리자 계정 1개만 만들어 사용하면 충분히 안전하지만,
  더 엄격하게 특정 관리자 UID만 허용하고 싶다면 규칙에 `request.auth.uid == "관리자UID"` 조건을 추가하세요.
